# Video plugins — placeholder / out of scope

This directory is reserved for a future video-domain plugin pack. It is **not** part of the current Graphyn plugin inventory.

- No `plugin.toml` manifests are shipped here.
- `PluginManager` does **not** auto-install anything from this folder.
- For production graphs, use the **Audio** and **Common** packages under `PluginPackage/`.

If video nodes are added later, each plugin should follow the standard layout documented in `PluginPackage/ARCHITECTURE.md`.
